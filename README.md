# Takshashila IQ — BPSC PatternMaster (Next.js 14 + TypeScript)

A modern, zero-latency EdTech web application built to help Bihar Public Service Commission (BPSC CCE) aspirants master the recurring 10-question Quantitative Aptitude & Mental Ability section through template recognition and dynamic variation cloning.

## Quick Start
```bash
npm install
npm run dev
```

## Core Architecture
- `src/components/PatternMasterApp.tsx`: Unified client application containing the Archetype Hub, Interactive Archetype Studio, 15-Minute Timed Exam Sprint Mode, and LaTeX/KaTeX renderer.
- `src/app/layout.tsx`: Root App Router layout with KaTeX stylesheet and dark-mode styling.
